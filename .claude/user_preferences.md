**技术背景:** 熟悉 FastAPI、Python、SQLAlchemy、Jinja2 模板开发，使用 Windows 环境开发

**沟通风格:**
- 直接指出问题，不绕弯子
- 期望看到具体修复方案而非冗长解释
- 使用中文交流，项目也以中文为主

**协作方式:**
- 喜欢逐个功能自测验证
- 不要求操作 git（自己处理 git 操作）
- 期望功能改动在本地代码中完成，自测后自己上库到 GitHub
- 对 UI 文案敏感（如"URL 重命名"→"文件管理"等命名一致性）

**敏感信息注意:** 明确要求避免泄露密钥等敏感数据到记忆/文档中

**Why:** 开发者风格直接，注重效率和结果
**How to apply:** 回复直切要点，给出具体代码改动而非讨论方案。不提及也不保存任何 .env 中的密钥值。
