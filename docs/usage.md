# 文档托管平台使用文档

## 简介

文档托管平台是一个企业级文档在线托管和分享系统。支持上传 HTML 文档以及各类静态文件，通过飞书账号即可快速登录管理。

---

## 快速开始

### 1. 登录平台

1. 打开浏览器访问平台地址
2. 点击右上角 **"登录"** 按钮
3. 使用飞书扫码或账号密码登录
4. 登录后右上角显示你的头像和昵称

### 2. 创建项目

1. 点击导航栏 **"我的项目"**
2. 点击 **"+ 创建项目"** 按钮
3. 填写项目信息：
   - **项目名称**：给你的项目起个名字
   - **可见路径**：用于 URL 访问的唯一路径（如 `engineering-docs`）
   - **安全等级**：选择访问权限级别
   - **访问密码**：可选，设置后需密码才能访问
   - **允许目录列表**：关闭后可防止文件被遍历扫描
4. 点击 **"创建项目"**

### 3. 上传文档

1. 在"我的项目"中，点击项目卡片上的 **"上传"** 按钮
2. 可以：
   - 拖拽文件到虚线区域
   - 点击 **"选择文件"**
   - 点击 **"选择文件夹"**（保留目录结构）
3. 等待上传完成，查看上传结果

### 4. 访问文档

- 公开项目（L1/L2）：直接通过 URL 访问
- L3 项目：需要登录飞书后访问
- L4 项目：需要登录并提交访问申请，经项目管理员审批后方可访问

---

## 安全等级说明

| 等级 | 访问方式 | 适用场景 |
|------|----------|----------|
| **L1** | 完全公开，无需任何认证 | 对外文档、公开知识库 |
| **L2** | 公开，无需登录 | 内部公开文档（与 L1 暂无明显区别，预留给未来内外部公开区分） |
| **L3** | 需飞书登录后访问 | 内部敏感文档 |
| **L4** | 需飞书登录 + 提交访问申请，管理员审批通过后访问 | 机密文档、权限受限内容 |

> **注**：所有等级均可额外叠加密码保护。

## URL 重命名

将上传的文件自定义访问 URL。

### 使用场景

上传了 `aaa.html`，希望以 `testpage` 访问：

```
原始:  http://host/project/engineering-docs/aaa.html
命名后: http://host/project/engineering-docs/testpage
```

### 操作步骤

1. 在项目卡片点击 **"URL重命名"**
2. 找到要重命名的文件
3. 在"自定义 URL 名称"列输入想要的名称
4. 点击 **"保存"**
5. 清除命名可点击 **"清除"** 恢复原路径

### 注意事项

- URL 名称在同一项目内唯一
- 命名后原路径将不可访问（返回 404）
- 支持字母、数字、下划线和短横线

## L4 审批流程

### 作为申请者

1. 访问 L4 项目时，会看到"无权限"页面
2. 如已登录飞书，可填写申请理由并点击 **"提交访问申请"**
3. 管理员会收到飞书消息卡片
4. 审批通过后，你将收到飞书通知（绿色卡片），点击链接即可访问
5. 审批被拒绝时，你将收到红色卡片通知

### 作为管理员（项目创建者）

1. 申请人提交请求后，你会收到飞书消息卡片
2. 卡片显示申请人和申请时间
3. 点击 **"同意"** 或 **"拒绝"** 按钮处理
4. 也可以在"我的项目"中进入项目卡片 → **"审批"**，统一管理
5. 审批记录可在"待处理/已批准/已拒绝"标签页中查看

## 收藏功能

1. 登录后浏览项目文件时，可以收藏文件或目录
2. 点击导航栏 **"我的收藏"** 查看已收藏的内容
3. 每个收藏项显示项目名称和文件路径
4. 点击 **"取消收藏"** 可移除

---

## 目录列表

访问项目目录时：

- **允许目录列表（默认）**：显示目录中所有文件和子目录，有 index.html 时自动渲染
- **禁止目录列表**：访问目录路径返回 404，只能通过直接访问已知文件路径打开

> 敏感项目建议关闭目录列表，防止文件被遍历扫描。

## 常见问题

### Q: 为什么上传后访问文件显示 404？

可能原因：
1. 目录列表已关闭，需要通过直接文件路径访问
2. 文件已被设置了 URL 重命名，原路径被禁用
3. 文件尚未上传完成

### Q: 如何分享文件给其他人？

根据安全等级的不同：
- **L1/L2**：直接分享文件 URL 即可
- **L3**：对方需要用飞书登录
- **L4**：对方需要登录并提交访问申请

### Q: 忘记项目密码怎么办？

目前不支持找回密码。如有需要可以删除项目重新创建，或联系管理员处理。

### Q: 上传文件夹时目录结构会保留吗？

会。使用"选择文件夹"上传时，文件在服务器上保持原有的目录结构。

### Q: L4 审批后多久能访问？

审批通过后即时生效，无需刷新页面即可访问。
