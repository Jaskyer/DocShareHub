快速上手#

1. 登录平台#

打开浏览器访问平台地址，点击右上角 "登录" 按钮

使用飞书扫码或账号密码登录

登录后右上角显示你的头像和昵称，导航栏出现 "我的项目"

2. 创建项目#

点击导航栏 "我的项目"，然后点击 "+ 创建项目"

填写项目信息：项目名称、可见路径、安全等级等

点击 "创建项目"，完成创建

3. 上传文档#

在"我的项目"中，点击项目卡片上的 "上传" 按钮

拖拽文件到虚线区域，或点击选择文件 / 文件夹

等待上传完成，查看上传结果统计

4. 访问文档#

根据安全等级不同，访问方式有所区别：

  • L1 / L2 — 直接通过 URL 访问，无需任何认证
  • L3 — 需要飞书登录后访问
  • L4 — 需登录并提交访问申请，项目管理员审批通过后访问

安全等级说明#

平台提供四级安全体系，满足从公开到机密的各类文档防护需求。

L1

完全公开

无需任何认证，所有人可直接访问。适合对外文档、公开知识库。

L2

公开

无需登录，与 L1 暂无明显区别，预留给未来内外部公开区分。

L3

登录可见

需要飞书登录后才可访问。适合内部敏感文档。

L4

申请审批

需要飞书登录 + 提交访问申请，管理员审批通过后访问。适合机密文档。

ℹ
提示

所有等级均可额外叠加密码保护，访问时需要输入密码。

URL 重命名#

将上传的文件自定义访问 URL。例如上传 aaa.html，设置 URL 名称为 testpage：

# 原始路径
http://host/project/engineering-docs/aaa.html

# 命名后
http://host/project/engineering-docs/testpage

操作步骤

在项目卡片点击 "URL重命名"

找到要重命名的文件

在输入框中输入想要的 URL 名称，点击 "保存"

清除命名可点击 "清除"，恢复原路径访问

⚠
注意

命名后原路径将不可访问（返回 404）。URL 名称在同一项目内唯一，仅支持字母、数字、下划线和短横线。

L4 审批流程#

L4 项目需要提交访问申请，经管理员审批后方可查看内容。审批全程通过飞书消息卡片完成，即时高效。

作为申请者

访问 L4 项目时，看到"无权限"页面

已登录飞书的情况下，可填写申请理由并点击 "提交访问申请"

管理员会收到飞书消息卡片，含"同意"/"拒绝"按钮

审批通过后收到绿色卡片通知，点击链接即可访问

审批被拒绝时收到红色卡片通知

作为管理员（项目创建者）

直接在飞书中点击消息卡片的 "同意" 或 "拒绝" 按钮

或在"我的项目"中进入项目 → "审批" 页面统一管理

审批记录可在"待处理 / 已批准 / 已拒绝"标签页中查看

收藏功能#

登录后可以收藏文件或目录，方便快速访问高频内容。

  • 浏览项目文件时，点击收藏图标收藏文件或目录
  • 点击导航栏 "我的收藏" 查看所有收藏内容
  • 每个收藏项显示项目名称和文件路径，一目了然
  • 点击 "取消收藏" 可移除

目录列表#

控制项目目录是否允许被浏览：

  • 允许目录列表（默认） — 访问目录时显示所有文件和子目录列表。存在 index.html 时自动渲染
  • 禁止目录列表 — 访问目录路径时返回 404，只能直接访问已知文件路径
ℹ
建议

敏感项目关闭目录列表，防止文件被遍历扫描。

常见问题#

  • 目录列表已关闭，需要通过直接文件路径访问
  • 文件已被 URL 重命名，原路径被禁用
